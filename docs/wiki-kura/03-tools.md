## Tools

### Filters

Filters go into a **filter slot** (Inventory Configurator, Inventory Hopper, Inventory Interface). You can also put any normal item in a filter slot: then only that item passes.

| Filter | How to set it up |
|---|---|
| **Item Filter** | Right-click it, then click slots with items to add them. Switch between "allow only these" and "block these", and between "any item of this kind" and "exact match" (names, enchantments). |
| **Tag Filter** | Right-click it, put an item in the top row, then click below it to pick one of its groups - e.g. all logs, all wool, all flowers. |
| **Polymorphic Filter** | Nothing to set: only lets in items the container already holds. Great for keeping each chest for the items it already has. |

### Inventory Configurator

Right-click a chest that is part of a network to change how the network uses it:

* **Priority** (lowest to highest): higher priority chests fill first and are emptied last.
* **Filter**: only matching items go in.
* **Left out of networks**: the network skips this chest completely.
* **Keep last item**: leaves one item in each slot, so the slot stays reserved for that item.
* **Show network**: lights up every block of the network.

Right-click a hopper, emitter or interface with it to open its settings.

### Wireless terminals

* **Wireless Terminal** - right-click while looking at a terminal up to 16 blocks away.
* **Advanced Wireless Terminal** - sneak + right-click a terminal to bind it, then right-click anywhere within 64 blocks. A **beacon** within 8 blocks of the terminal makes it reachable from anywhere in the same world (level 1-3) or from any world (level 4).

### Paint Kit

Right-click any full block to pick its look, then right-click a Framed Cable (or an old Inventory Trim) to give it that look. Sneak + right-click to clear it. The kit wears out after 64 uses.
