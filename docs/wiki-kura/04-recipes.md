## Recipes

Shaped recipes are shown as rows (top / middle / bottom); a dot is an empty slot. Shapeless recipes can be put in any order.

| Item | Recipe |
|---|---|
| Inventory Connector | . R . / C H C / . R . - R redstone, C copper ingot, H chest |
| Storage Terminal | C G C / R Q R / C C C - C copper ingot, G glass pane, R redstone, Q comparator |
| Crafting Terminal | Storage Terminal + crafting table + gold ingot |
| Inventory Trim (4) | S P S / P . P / S P S - S stick, P any planks |
| Inventory Cable (6) | C R C - copper ingot, redstone, copper ingot |
| Framed Inventory Cable | Inventory Cable + 2 sticks |
| Cable Connector | Inventory Cable + copper ingot + redstone |
| Inventory Hopper | Hopper + copper ingot + redstone |
| Level Emitter | Comparator + redstone torch + copper ingot |
| Inventory Interface | Barrel + 2 copper ingots + redstone |
| Open Crate | Barrel + iron bars |
| Filing Cabinet | I P I / P H P / I P I - I iron ingot, P paper, H chest |
| Wireless Terminal | Storage Terminal + ender pearl + gold ingot + redstone |
| Advanced Wireless Terminal | Wireless Terminal + eye of ender + diamond + gold ingot |
| Item Filter (2) | 2 paper + copper ingot |
| Tag Filter | Item Filter + book |
| Polymorphic Filter | Item Filter + chest |
| Inventory Configurator | Stick + copper ingot + redstone + glass pane |
| Paint Kit | Brush + red dye + green dye + blue dye |

**Recipes on the website**

All Steamworks, Kitchen and Kura recipes are also listed on the website: **Play > Recipes**. That page has a search and a type filter, and a short guide to Zukan.
