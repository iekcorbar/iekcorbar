## Upgrades and Recipes

An upgrade is a plate you put in one of the backpack's upgrade slots (the bottom row). Each kind works once per backpack. Upgrades work while the backpack is anywhere in your inventory, but not while you have that backpack open.

### Upgrades

* **Pickup Upgrade.** Everything you walk over goes straight into the backpack, as long as it fits. (The server can set this to "only kinds already in the backpack".)
* **Magnet Upgrade.** Pulls dropped items within a few blocks towards you. Together with a Pickup Upgrade they end up in the backpack.
* **Feeding Upgrade.** When you are hungry, the backpack eats food for you. It never eats food with side effects, like rotten flesh or golden apples.
* **Everlasting Upgrade.** When the backpack is dropped, it never despawns, burns or falls into the void.
* **Deposit Upgrade.** Sneak + right-click a chest with the backpack: items the chest already holds move into it.
* **Restock Upgrade.** Sneak + right-click a chest with the backpack: items the backpack already holds are taken from the chest.
* **Refill Upgrade.** Tops up the stacks in your hotbar from the backpack when they run low (below half a stack).

### Recipes

All upgrades are crafted without a shape: put the Upgrade Base and the other items anywhere on the grid.

| Item | Recipe |
|---|---|
| Upgrade Base | 4 iron nuggets, 4 leather and 1 string (a ring: nuggets in the corners, leather on the sides, string in the middle) |
| Pickup Upgrade | Upgrade Base + hopper |
| Magnet Upgrade | Upgrade Base + ender pearl + iron ingot |
| Feeding Upgrade | Upgrade Base + golden carrot + bread |
| Everlasting Upgrade | Upgrade Base + nether star + obsidian |
| Deposit Upgrade | Upgrade Base + chest + piston |
| Restock Upgrade | Upgrade Base + chest + sticky piston |
| Refill Upgrade | Upgrade Base + comparator + hopper |
